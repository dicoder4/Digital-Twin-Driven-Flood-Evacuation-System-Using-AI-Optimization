================================================================================
                    SPEED & PHYSICS LOGIC SUMMARY
================================================================================

SPEED MODES (Backend SPEED_MAP):
  🚗 Car:  30 km/h  (urban traffic, default)
  🚴 Bike: 15 km/h  (cycling speed)
  🚶 Walk:  4 km/h  (human walking pace)

ETA CALCULATION (Dynamic):
  ETA_minutes = (distance_km / speed_kph) * 60

  Examples for 5 km route:
    Car:  (5 / 30) * 60 = 10 minutes
    Bike: (5 / 15) * 60 = 20 minutes
    Walk: (5 / 4)  * 60 = 75 minutes

FLOOD PHYSICS (from core system):

  Water Depth Ranges:
    > 1.5m          → IMPASSABLE (all modes blocked)
    0.8 - 1.5m      → HIGH FLOOD (risky for bike/walk)
    0.4 - 0.8m      → MODERATE (all modes ok, caution)
    0.1 - 0.4m      → LIGHT (normal travel)
    < 0.1m          → SAFE (no flooding)

  A* Cost Function:
    cost = travel_time + flood_penalty
    travel_time = (edge_length_km / speed_kph) * 60
    flood_penalty = water_depth * 1000.0

    Result: Routes with less flooding are preferred

FRONTEND LOGIC:

  1. CONFIG Phase (Route Preview)
     - User selects speed mode (car/bike/walk)
     - Frontend calculates: ETA = (distance / speed) * 60
     - Shows updated ETA immediately
     - Displays flood impact note based on max_depth

  2. RUNNING Phase (Live Navigation)
     - Person moves every 5 seconds (tick)
     - Flood depth monitored
     - If depth increases → Show warning
     - If depth > 1.5m → Trigger rerouting
     - Update progress and time remaining

  3. COMPLETE Phase (Summary)
     - Shows final distance, time, flood depth
     - Confirms safety (depth < 1.5m = safe)

RESPONSE STRUCTURE:

  Primary Route:
  {
    "route_geojson": {...},
    "summary": {
      "total_distance_m": 5000,        ← Fixed
      "eta_minutes": 10,               ← Speed-dependent (30 km/h)
      "max_flood_depth_m": 0.45,       ← From physics
      "safe": true,                    ← (0.45 < 1.5)
      "flooded_segments": 2            ← From physics
    }
  }

  Alternative Routes: [same structure for each]

EVERYTHING ALIGNED:
  ✅ Speed modes logical (realistic urban speeds)
  ✅ ETA dynamic based on speed selection
  ✅ Flood depths from core physics simulation
  ✅ Routing cost includes both time and flood penalty
  ✅ Impassable routes (> 1.5m) trigger rerouting
  ✅ Notifications aligned with physics thresholds
