================================================================================
                         TROUBLESHOOTING
================================================================================

If backend doesn't start:
  - Check imports: python -c "from simulate_routes import simulate_router"
  - Verify MongoDB is running
  - Check Python environment

If frontend shows blank:
  - Check console (F12) for errors
  - Verify API_URL in src/config.js
  - Check network tab for API calls

If routes don't show:
  - Check browser console for alternative_routes
  - Verify backend response includes alternative_routes
  - Try different coordinates (larger distance)

If ETA doesn't change:
  - Verify speed mode selector changes value
  - Check that route preview recalculates
  - Test calculation manually: 5km by car (30km/h) = 10min

If markers don't drag:
  - Make sure you're clicking on the marker itself
  - Try different browsers
  - Check console for drag event errors
